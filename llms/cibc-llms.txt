# CIBC (Canadian Imperial Bank of Commerce)

> Canadian Imperial Bank of Commerce (CIBC) is a Schedule I domestic chartered bank and one of Canada's Big Six, headquartered in Toronto. CIBC runs no first-party public developer portal (developer.cibc.com does not resolve) and publishes no downloadable OpenAPI/Swagger specifications. Consumer-permissioned data access today is aggregator-mediated (MX, Plaid), and corporate connectivity is offered through CIBC SWIFT Corporate Access (SCA) file exchange rather than a public REST API — pending Canada's coming Consumer-Driven Banking regime overseen by the FCAC.

- [Cash Management Services](https://www.cibc.com/en/commercial/business-solutions/managing-cash-flow/cash-management-services.html): Commercial cash-management offering, including SWIFT Corporate Access (SCA) file exchange for corporate connectivity.
- [CIBC via Plaid](https://plaid.com/institutions/cibc/): Aggregator-mediated, consumer-permissioned data access (Assets, Auth, Balance).

## Notes

- No public OpenAPI, GraphQL SDL, or MCP server is published by CIBC as of this writing.
- Canada's Consumer-Driven Banking framework (legislated Budget 2024 / 2024 Fall Economic Statement, overseen by the Financial Consumer Agency of Canada) is not yet operational; open-banking API access remains voluntary and aggregator-mediated.
